# Example input data

`example_input.xlsx` is a synthetic demonstration dataset generated for testing the public script. It contains no patient records and must not be interpreted as study data.

Expected format:
- Column A: binary outcome (`0/1`, `Healthy/MALT+`)
- Column B: numeric RFI feature
- Each row represents one independent sample

No patient-identifier column is required or used by the public script.

Do not commit real patient-level or otherwise identifiable data.
